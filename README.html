專案概觀

`LAH-FE`（Land Administration Hub - Frontend）為地政智慧控管系統的前端核心應用程式。系統整合了登記案件管理、測量小幫手、資訊機房戰情看板、地價查調工具與即時通訊等多項功能。

架構全面採行 純靜態 SPA (Static SPA) + PM2 背景排程 (LAH-SCHEDULER) 雙軌設計：前端靜態網頁由 Apache 8080 埠直接託管；背景排程與環境變數動態同步則由 PM2 常駐守護。系統已全面相容最新 Node.js v26.13.0 執行期環境。

技術棧

專案以 Nuxt.js 2.15.8 (Vue 2.7.16) 為核心，搭配 BootstrapVue 2.23.0 構建現代化管理介面。樣式編譯已現代化至 Dart Sass，並相容現代 Node.js 執行期環境。
